# Quality Dimensions

Use these dimensions while building and self-reviewing.

- `request_fidelity`: The game answers the creator request, including requested surface, genre, mechanics, assets, references, and tone.
- `core_loop_fun`: The game is worth playing for at least five minutes because it has tension, agency, feedback, and a payoff.
- `controls`: Input feels natural on the primary surface and common genre expectations are respected.
- `polish`: Visuals, animation, audio, HUD, camera, scale, and moment feedback feel deliberate and coherent.
- `stability`: The game starts, plays, restarts, and maintains usable performance without visible errors.
- `store_listing`: Listing assets and metadata accurately represent the actual game and are complete enough for PlayDrop discovery.

Do not treat this as a coding checklist. The player experience is the target.
