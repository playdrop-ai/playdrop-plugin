# Remix Game Phases

Choose phases that match the transformation. A common remix may move through Reviewing or Researching, Designing, whichever build phases are needed, Playtesting, Recording, and Finalizing, but no phase is present merely to fill that example.

Use the same supported vocabulary as new games. `study-source` maps to Researching, `remix-design` to Designing, and `transform` to Coding for compatibility.

- Inspect the source before deciding what to reuse and what to change.
- Decide and claim the remix title, subtitle, slug, and primary surface together.
- Preserve source ancestry while making a meaningful mechanical, structural, fantasy, or input transformation.
- Share only media newly created or materially changed for the remix, immediately after inspection.
- Use the public PlayDrop validation, playtest, listing, and upload workflows.

A remix is not a reskin. It should be recognizably derived but worth playing separately.
