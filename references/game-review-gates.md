# Game Review Gates

Every review should name one current gate. The gate is descriptive. It does not change the rubric. It frames feedback and next steps.

Gate source files:

1. [Concept](game-review-gates/concept.md)
2. [Gameplay Prototype](game-review-gates/gameplay-prototype.md)
3. [Demo](game-review-gates/demo.md)
4. [Vertical Slice](game-review-gates/vertical-slice.md)
5. [First Release](game-review-gates/first-release.md)
6. [Mature Live Version](game-review-gates/mature-live-version.md)

Usage rules:

- Choose exactly one current gate per review.
- Use the gate files to frame recommendations, not to relax scoring standards.
- These gate references are reusable across public PlayDrop review and improvement skills.
