# Game Review Feedback Format

Both outputs are plain text. Do not use markdown tables. Do not use HTML. Keep headings exact.

## Internal assessment format

```text
Outcome: <Blocked|Limited|Passed|Good|Excellent>
Current gate: <gate>
Primary reviewed surface: <MOBILE_PORTRAIT|MOBILE_LANDSCAPE|DESKTOP>
Primary player verb: <verb>
Primary interaction evidence: <exact input sequence attempted and the concrete gameplay result>
Challenge evidence: <what creates challenge, tension, mastery, or why those are absent>
Comparable benchmark: <closest credible game or genre set>
Overall assessment: <paragraph>
Punchline assessment: <one short sentence for the final rating card>
Score caps applied: <none|short list of caps and affected dimensions>
Criteria ratings:
- Gameplay / Core Loop: <rating>/10 | <comment>
- Depth / Replayability: <rating>/10 | <comment>
- Controls / Input: <rating>/10 | <comment>
- UX / Usability: <rating>/10 | <comment>
- First Time User Experience: <rating>/10 | <comment>
- Visuals / Art Direction: <rating>/10 | <comment>
- Audio / Feedback: <rating>/10 | <comment>
- Store Listing & Metadata Accuracy: <rating>/10 | <comment>
- Safety / Age Rating / Compliance: <rating>/10 | <comment>
- Performance / Stability: <rating>/10 | <comment>
Gate assessment: <paragraph>
```

## Creator feedback format

```text
Current state: <gate>
Reviewed surface: <MOBILE_PORTRAIT|MOBILE_LANDSCAPE|DESKTOP>
Quality for current state: <one sentence>
Summary: <paragraph>
Quick wins:
1. <specific action>
2. <specific action>
3. <specific action>
Medium wins:
1. <specific action>
2. <specific action>
3. <specific action>
Next level:
1. <specific action>
2. <specific action>
3. <specific action>
```

Rules:

- Suggestions must be ultra specific.
- Prefer concrete next steps over abstract advice.
- When relevant, mention Playdrop packs, metadata fixes, platform affordances, or practical implementation options.
- Do not edit metadata or tags automatically. Only recommend corrections.
- When useful, ground feedback in comparable successful games or recognizable quality patterns rather than vague taste statements.
- Translate comparisons into implementable next steps instead of asking creators to imitate a reference game blindly.
