# Depth / Replayability

This dimension measures whether the game has lasting value beyond the first few minutes. Depth can come from systems, build variety, challenge, expression, progression, score optimization, social comparison, or authored discovery. Replayability does not have to mean infinite content, but it does have to mean the player has a reason to return or continue engaging.

## Comparison discipline

Compare to games with similar session structure and retention goals.

- roguelite runs compare against build variety and adaptation in games like `Hades`, `Slay the Spire`, or `Balatro`
- arcade score games compare against "one more run" pressure like `Downwell`, `Super Hexagon`, or `Tetris Effect`
- short authored narrative or puzzle games may compare less on replayability and more on density of insight or novelty

Ask whether the game is aiming for repeat mastery, long-term progression, short-form delight, or a single crafted experience. Judge it against that promise.

## What to inspect

Look for:

- meaningful decisions that change the run
- systems that interact rather than simply accumulate
- reasons to replay, improve, experiment, or complete unfinished goals
- tension between risk and reward
- progression that changes player planning instead of just adding numbers

## Evidence to gather

- play past the first obvious loop
- observe whether new possibilities open up or whether the game simply repeats
- note whether depth is visible but not yet fully developed, or absent entirely
- if progression exists, inspect whether it changes play or merely lengthens it

## Questions to answer

- What makes a second session attractive?
- Does the game generate new decisions over time?
- Are there emergent combinations, alternate strategies, unlocks, mastery goals, or leaderboard motivations?
- If it is meant to be short, does it still feel complete and thoughtfully structured?

## Common failure modes

- the game has only one viable approach
- repetition arrives before mastery does
- upgrades exist, but they do not materially change decision-making
- the experience depends on future content that is not present yet
- replay is theoretically possible but emotionally unmotivated

## Stage-aware interpretation

A `Gameplay Prototype` does not need full retention systems, but it should show the shape of future depth or prove that the base interaction can support repeat play. A `Vertical Slice` should already demonstrate how depth expands. A `Mature Live Version` is expected to show durable reasons to come back.

## What strong feedback looks like

Useful notes distinguish missing breadth from missing depth:

- "There are only three enemy types, which is a breadth issue, but the larger problem is that every run is solved the same way, which is a depth issue."
- "The game is short by design, but each level adds a new rule cleanly, so it feels authored rather than thin."
