# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful in issues and discussions; harassment, abuse and spam are removed.

Report conduct concerns privately to [support@playdrop.ai](mailto:support@playdrop.ai). Maintainers review every
report and may edit or remove content, or block participants who violate this code.
