# Phaser 2D Game

Requires the PlayDrop CLI. If the `playdrop` command is unavailable, follow the PlayDrop `setup` skill first.

Use this only after `create-game` records `phaser-2d` as the engine decision. Do not load the Three.js engine skill for the same game.

Read and follow `../../references/tech/phaser-2d.md` completely.
